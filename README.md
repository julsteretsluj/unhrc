# UNHRC — SEAMUN I 2027

Committee microsite for the **United Nations Human Rights Council** at SEAMUN I (16–17 January 2027).

Built to match [seamun.com](https://seamun.com) and sibling portals (`unsc.seamun.com`, `presscorps.seamun.com`), with UNHRC blue accents.

## Contents

- Agenda topics, 30 country allocations, Group 1 schedule
- Placeholders for RoP, position paper portal, and chair report
- Committee wheel + dove access gate (same flow as other SEAMUN committee sites)
- Links to official forms on seamun.com

## Local preview

```bash
python3 -m http.server 8777
```

Open `http://localhost:8777`. Use the wheel → Continue into UNHRC → free the dove (or Skip) to enter the site.
